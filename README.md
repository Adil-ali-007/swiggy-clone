# 🍔 Swiggy Clone — Tomato

A responsive food delivery web application inspired by Swiggy, built using **React and Vite**.

## 🚀 Live Demo

👉 **View Tomato-Live**

## 📖 About the Project

**Tomato** is a Swiggy-inspired food delivery application that demonstrates modern frontend development using React.

The project includes restaurant and food listings, search functionality, cart management, responsive design, and state management with Redux Toolkit.

## 🛠️ Tech Stack

* **Frontend:** React
* **Build Tool:** Vite
* **State Management:** Redux Toolkit
* **Styling: Tailwind** CSS

## ✨ Features

* 🍔 Restaurant and food listings
* 🔍 Search functionality
* 🛒 Shopping cart
* ➕ Add food items to cart
* ➖ Remove food items from cart
* 📱 Responsive design
* ⚡ Dynamic UI
* 🔄 Redux Toolkit state management

## ⚙️ Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the project:

```bash
cd swiggy-clone
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available on the local development server provided by Vite.
